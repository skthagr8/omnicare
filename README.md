# OmniCare - Elderly Care Management System

## Overview
OmniCare is a comprehensive platform for managing elderly care services, featuring:
- Real-time caregiver scheduling and GPS tracking
- Clinical assessment tools (TUG, CMAI, Braden, Delirium)
- ML-powered risk prediction
- Guaranteed emergency notification system
- Family portal for transparency

- Docker Compose
